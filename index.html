Sweet Spot
เริ่ม 25% จบ 80%

ช่วง 20%–80% เหมาะกับการใช้งานประจำวัน ช่วยลดความเครียดสะสมของเซลล์แบตเตอรี่ได้ดีครับ

💡 ทริคถนอมแบต

กฎ 20% - 80% สำหรับวันใช้งานทั่วไป

การชาร์จช่วง 20% ถึง 80% ในชีวิตประจำวันช่วยให้แบตเตอรี่ทำงานในย่านที่สบาย ไม่เกิดความร้อนสะสมสูง และยืดอายุการใช้งานได้ยาวนาน

ทริค: หากตั้งเวลาชาร์จช่วง Off-Peak (หลัง 22:00 น. วันธรรมดา หรือเสาร์-อาทิตย์) จะช่วยลดค่าไฟได้มาก

☁️ เชื่อมต่อ Google Sheet

Sheet ID เป้าหมาย: 1rXLCqETmVvJt6Msy6WaMhwmPaoIU7Fcr หากวาง URL ของ Google Apps Script Web App ด้านล่าง ข้อมูลที่บันทึกจะส่งไปลงชีทด้วย

โค้ด Apps Script สำหรับชีทนี้:
const SHEET_ID = '1rXLCqETmVvJt6Msy6WaMhwmPaoIU7Fcr';
function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.openById(SHEET_ID);
  const sheet = ss.getSheetByName('Charge_Log') || ss.getSheets()[0];
  sheet.appendRow([
    data.date, data.startSoc, data.endSoc, data.addedPct,
    data.netKwh, data.grossKwh, data.tariffMode, data.cost,
    data.co2Saved, data.score, data.monthKey, data.note || ''
  ]);
  return ContentService.createTextOutput(JSON.stringify({ ok: true }))
    .setMimeType(ContentService.MimeType.JSON);
}
